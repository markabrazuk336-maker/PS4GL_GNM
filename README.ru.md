# PS4GL_GNM

**Графика в стиле OpenGL ES для взломанной PS4: прямо на видеокарте через GNM, без SDK Sony.**

[English version](README.md)

PS4GL_GNM — небольшой графический драйвер для homebrew на PS4. Программа вызывает обычные функции `glXxx`, а драйвер превращает их в команды видеокарте (PM4). В комплекте свой компилятор шейдеров GLSL → GCN: он работает на ПК и построен на обычном LLVM.

Почему не Piglet, системная библиотека OpenGL? Piglet запускается только в системных приложениях (категория `gde`), а им достаётся около 768 МБ памяти. Компилятора шейдеров на обычной консоли у него тоже нет. Обычному игровому пакету (`gd`) доступно около 4,5 ГБ, и PS4GL_GNM работает именно там.

## Состояние проекта

- Драйвер рисовал сложные 3D-сцены в 60 FPS на PS4 Pro с GoldHEN.
- Пример с кубом из этого репозитория собирается в `.pkg`, а его команды видеокарте проверены на стенде на ПК. **На консоли он ещё не запускался.**
- Проект молодой, возможности пока ограничены. Подробнее в разделе [Ограничения](#ограничения).

## Что нужно

**На консоли:** взломанная PS4 с [GoldHEN](https://github.com/GoldHEN/GoldHEN). Он нужен, чтобы ставить и запускать пакеты с поддельной подписью.

**На ПК:**

- [OpenOrbis PS4 Toolchain](https://github.com/OpenOrbis/OpenOrbis-PS4-Toolchain) и переменная среды `OO_PS4_TOOLCHAIN` с путём к нему
- [LLVM](https://llvm.org/) в `PATH` с целью AMDGPU: `clang`, `clang++`, `ld.lld`, `llc`, `opt`, `llvm-link`, `llvm-objcopy`, `llvm-mc` (проверено на LLVM 19.1)
- Python 3.8 или новее
- среда .NET для `PkgTool.Core` из тулчейна

## Сборка примера

Пример рисует цветной треугольник и вращающийся куб с текстурой.

PowerShell:

```powershell
$env:OO_PS4_TOOLCHAIN = "C:\OpenOrbis\PS4Toolchain"
python build.py
```

bash:

```bash
export OO_PS4_TOOLCHAIN=~/OpenOrbis/PS4Toolchain
python3 build.py
```

Готовый пакет появится в `build/cube/IV0000-PSGL00001_00-PS4GLCUBE0000000.pkg`. Скопируйте его на консоль и установите через Package Installer в GoldHEN.

## Как подключить драйвер

Добавьте в свой проект `src/ps4gl.cpp` (и при желании `src/ps4gl_heap.c`), укажите папки `include/` и `src/` для заголовков и подключите `-lSceVideoOut -lSceGnmDriver -lSceSystemService`.

```cpp
#include "ps4gl.h"

int main()
{
    ps4glInit( 0 );                               // 1920x1080, 1 ГБ видеопамяти

    GLuint vs = glCreateShader( GL_VERTEX_SHADER );
    glShaderBinary( 1, &vs, 0, vsData, vsSize );  // собран на ПК через tools/sbmake.py
    // ... обычная настройка OpenGL ES 2 ...

    for ( ;; )
    {
        glClear( GL_COLOR_BUFFER_BIT | GL_DEPTH_BUFFER_BIT );
        glDrawElements( GL_TRIANGLES, count, GL_UNSIGNED_SHORT, 0 );
        ps4glSwapBuffers();
    }
}
```

Шейдеры собираются заранее:

```bash
python tools/sbmake.py shader.vert -o shader.vert.sb
```

Журнал драйвера лежит в `/data/ps4gl/log.txt`. Функция `ps4glSetLogCallback` направляет его в другое место.

## Что поддерживается

| Область | Что есть |
|---|---|
| Буферы | Вершины и индексы, `glBufferSubData`, `glMapBufferRange`, индексы на 8, 16 и 32 бита |
| Текстуры | RGBA8, RGB, BGRA, яркость и альфа, 4444/5551/565, 16-битные и float-форматы, мип-уровни |
| Сжатые текстуры | DXT1, DXT3, DXT5 (распаковываются в RGBA8 при загрузке) |
| Шейдеры | Вершинные и пиксельные на GLSL, до 16 текстур в шейдере, 16 атрибутов вершин |
| Глубина | 32-битная с плавающей точкой, все функции сравнения, смещение полигонов |
| Смешивание | Все коэффициенты и уравнения, отдельная альфа |
| Цели рендера | FBO с цветом и глубиной, `glBlitFramebuffer` |
| Прочее | Ножницы, отсечение граней, маска цвета, объекты сэмплеров |
| Вывод на экран | Тройная буферизация, 60 FPS с вертикальной синхронизацией |

## Ошибки GNM и как драйвер их обходит

На поиск этих проблем ушло больше всего времени, поэтому они записаны здесь для всех, кто работает с GNM напрямую.

| Проблема | Обход |
|---|---|
| `DRAW_INDEX_2` вешает видеокарту на части рисований | Рисуем через `DRAW_INDEX_AUTO`, а загрузчик вершин сам читает индекс из буфера |
| Текстуры BC/DXT в линейной раскладке вешают видеокарту | Распаковка в RGBA8 при загрузке |
| Цель рендера, прочитанная сразу после рисования, даёт рваные полосы | Сброс кэшей цвета и глубины при смене цели |
| Очистка 1080p через DMA стоит около 20 мс на кадр | Очистка прямоугольником на весь экран силами видеокарты |
| С тенью регистров очистка доходила только до части цели | Перед очисткой тень регистров сбрасывается |
| Каждая запись контекстного регистра может завести новый аппаратный контекст | Тень регистров: пишем только то, что изменилось |
| `sceGnmSubmitAndFlipCommandBuffers` падает без метки | В конце буфера команд стоит NOP на 64 слова с меткой PrepareFlip |
| Обход треугольников на экране и в FBO отличается | Передняя грань переворачивается для целей без отражения по Y |
| Гибкая память кончается примерно на 300 МБ | `ps4gl_heap.c` переносит `malloc` в прямую память |
| `malloc` с выравниванием 8 байт роняет код SSE, а мьютексы pthread падают на старте | Выравнивание 16 байт и спин-блокировка |

## Ограничения

- Экран всегда 1920x1080.
- Шейдеры собираются только на ПК. `glShaderSource` и `glCompileShader` ничего не делают.
- Компилятор понимает практичное подмножество GLSL. `gl_FragCoord`, `gl_FragDepth` и шейдеры, которым нужна scratch-память, не поддерживаются.
- Нет кубических и 3D-текстур, нет массивов текстур.
- Нет трафарета, MSAA, инстансинга и нескольких целей цвета сразу.
- Мип-уровни работают только у текстур RGBA8 со сторонами-степенями двойки и шириной от 64 пикселей.
- VAO, запросы и объекты синхронизации принимаются, но ничего не делают.
- `glReadPixels` возвращает нули, а `glGetError` всегда сообщает об отсутствии ошибок.
- Рисование с индексами без атрибутов вершин требует индексов, идущих подряд.

## Что где лежит

```text
include/ps4gl.h        публичный API
src/ps4gl.cpp          драйвер
src/ps4gl_heap.c       malloc на прямой памяти, по желанию (сгенерирован)
src/gen/               сгенерированные загрузчики вершин и таблицы
shaders/               библиотека функций GLSL и шейдеры самого драйвера
tools/sbmake.py        GLSL -> готовый шейдер PS4
tools/glsl2cl.py       GLSL -> OpenCL C (первый этап компилятора)
tools/sbformat.py      формат готовых шейдеров: чтение и запись
tools/sbdump.py        просмотр готовых шейдеров
tools/gen_*.py         генераторы файлов из src/
tools/mkpkg.py         ELF -> пакет .pkg для установки
samples/cube/          треугольник и вращающийся куб
```
